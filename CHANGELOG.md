# Changelog

## 1.1.0

- Expo config plugin: add `"@solankivishal/react-native-face-liveness"` to `plugins` in `app.json` and the camera permissions are set up for you (optional `cameraPermission` text).
- Android `detectInFile` also accepts bundled images (release-build resource names such as `assets_face`) and `android.resource://` URIs.

## 1.0.0

- First release: `FaceLivenessCamera` component and `FaceLiveness.detectInFile`.
